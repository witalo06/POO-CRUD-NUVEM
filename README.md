# CRUD de Produtos em Java (H2 Database)

Sistema simples de cadastro e gerenciamento de produtos via terminal (Console) desenvolvido em Java utilizando JDBC e banco de dados local embarcado **H2 Database**.

## Funcionalidades
* **1 - Inserir:** Cadastra um novo produto (Código, Nome e Preço).
* **2 - Listar:** Consulta um produto específico pelo código.
* **3 - Atualizar:** Altera o nome e o preço de um produto cadastrado.
* **4 - Deletar:** Remove um produto do banco pelo código.
* **0 - Sair:** Encerra a conexão com o banco e finaliza o programa.
